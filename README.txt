# yoshi ♥️ may — Love Website

## วิธีใช้
1. เปิด `editor.html` เพื่อแก้ชื่อ, IG, รูป, เพลง และข้อความ
2. กด **บันทึก**
3. กด **ดูเว็บ** เพื่อเปิดหน้าเว็บสำหรับแฟน

### สำคัญ
ข้อมูลที่หน้าแก้ไขบันทึกไว้ใน `localStorage` ของเบราว์เซอร์ จึงเหมาะสำหรับทดลอง/แก้บนเครื่องเดียวกัน
หากต้องการให้เว็บออนไลน์พร้อมข้อมูลรูปและเพลงเดียวกันบนทุกเครื่อง แนะนำให้แก้ไฟล์/อัปโหลด assets แล้วนำเว็บขึ้น GitHub Pages ในขั้นถัดไป

ไฟล์หลัก:
- `index.html` = หน้าเว็บสำหรับแฟน
- `editor.html` = หน้าแก้ไข
- `style.css` / `script.js`
- `editor.css` / `editor.js`
